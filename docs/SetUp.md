# テンプレート セットアップガイド

このリポジトリは、アプリケーション開発用テンプレートです。

## 技術スタック

- **Vite** - 高速なビルドツール
- **React 19** - UIライブラリ
- **AWS Amplify Gen2** - バックエンドサービス
- **MUI v7** - UIコンポーネントライブラリ
- **App Router v7** - ルーティング
- **PWA対応** - プログレッシブWebアプリ

## 初期設定

### 1. アプリケーション設定（`src/config/`）

アプリケーションごとに以下のファイルを変更してください：

#### `constants.ts`
- アプリケーションのタイトルを設定
- バージョン情報は`package.json`のバージョンを自動参照

#### `i18n.ts`
- 国際化対応のための設定ファイル

#### `navigationConfig.ts`
- ナビゲーションの設定
- サイドメニューとボトムナビゲーションの設定が可能

#### `routes.ts`
- ルーティングの設定ファイル
- 新規ページを作成する場合は、ここに追加
- `src/app/router.tsx`の設定は不要

### 2. PWAアイコンの変更

`public/`ディレクトリ内のアイコンファイルを、アプリケーションに応じて変更してください。

### 3. AWS Amplifyデプロイ設定

`amplify.yml`は、AWS Amplifyのデプロイ設定ファイルです。Node.js 20を使用するように設定されています。

## テーマ設定

### テーマファイルの場所
`src/theme/`にテーマ設定ファイルがあります。

### テーマの種類
- **MUIテーマ** - メインのテーマ設定
- **Amplifyテーマ** - MUIテーマでオーバーライド済み

### テーマのカスタマイズ
以下のファイルでテーマの設定ができます：
- `src/theme/mui/tokens/` - トークン設定
- `src/theme/mui/muiTheme.ts` - MUIテーマ設定

## デモページについて

### デモページの場所
`src/features/demo/` - デモ用のページ

フォルダ内で完結した構造になっているため、`src/features/home/Home.tsx`からデモページの参照を削除するだけで、フォルダごと削除できます。
